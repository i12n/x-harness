```text

                    --verify "node test/verify.js" --exec-image harness/execution:node22
  → Created smoke-repo ✅

  → Created prob-9d91ffd33b（status: INBOX）✅

  → CONFIRMED + confirmed_spec 落盘 ✅

Specification（**已知缺口**：无 CLI/Command 入口，改用 dist 服务创建，见 §6 findings #1）
  → spec-2159ed0591 READY ✅

ai spec show spec-2159ed0591     → Status: READY + Targets + Acceptance ✅
ai spec plan spec-2159ed0591     → PLANNED；task-spec-2159ed0591-0（INBOX）Replayed: no ✅
                                   同时自动创建 Delivery dlv-2ce75c9906 ✅
ai task show task-spec-2159ed0591-0 → targets/acceptance/description 正确，Runnable: no ✅
ai delivery show dlv-2ce75c9906  → Status: IN_PROGRESS；1 个 required Task；Release: (not released) ✅
```
